about=Pick which layer groups belong in the slideshow, set an interval, and the plugin shows one group at a time, hiding the others in the slideshow while leaving everything else (like a basemap) untouched. Playback runs bottom-to-top through the layer tree, supports looping, and can collapse to a small floating play/pause bar for unattended kiosk displays. Settings are saved into the project, so a kiosk project can start its slideshow automatically on open, and an optional legend panel shows the active group's symbology.

changelog=1.3.0
      - Settings (interval, loop, group selection, auto-start, legend) are saved in the project, so a kiosk .qgz carries its own show definition
      - New "Start automatically when this project opens" option for unattended displays
      - New "Restore visibility" button; the plugin also hands group visibility back as it found it when unloaded
      - New optional legend panel showing the active group's symbology, refreshed on each step
      - Fixed: an empty group made the legend heading blank, because an empty layer-tree group is falsy in Python (SIP maps __len__ to child count) — node checks now use "is not None"
      - Fixed: a deliberately empty group selection was resurrected as "all checked" when reloaded from the project
      - Fixed: saving a fractional interval raised TypeError inside a Qt slot, which aborts QGIS under PyQt6 (QgsProject.writeEntry exposes no double overload; the interval is now stored as integer milliseconds)
      - Settings reads and writes are defensive: a failure is logged to the Layer Slideshow log rather than taking QGIS down
      1.2.0
      - Fixed: unchecking every group was silently undone on the next list refresh
      - Fixed: Play did nothing after a non-looping show reached the end
      - Fixed: closing the panel left Play greyed out and Pause enabled, so the show could not be restarted
      - Fixed: adding, removing or renaming a group did not refresh the list (group changes are layer-tree events, not layer events)
      - Fixed: renaming a group mid-show silently dropped it from the rotation; the playhead now follows the rename
      - Warn when two top-level groups share a name, since groups are matched by name
      - Toolbar and menu action now use the plugin icon
      - Raised qgisMinimumVersion to 3.22 (the QAction compatibility shim this plugin relies on is not present in early 3.x)
      - Added a headless regression test suite (16 tests, passing on QGIS 3.44/Qt5 and 4.0.1/Qt6)
      1.1.0
      - QGIS 4 / Qt6 compatibility declared in metadata (supportsQt6, qgisMaximumVersion)
      - Added plugin icon
      - Bundled LICENSE inside the plugin package
      1.0.0
      - Initial release: group-based slideshow with play/pause/loop, interval control, and a minimize/expand kiosk bar
